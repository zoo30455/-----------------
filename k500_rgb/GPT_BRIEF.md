# Lenovo Legion K500: полное руководство по RGB-протоколу для ИИ-помощника

Этот документ — инструкция для языковой модели (ChatGPT и др.). Прочитав его, ты должен уметь
самостоятельно писать на Python программы, которые управляют подсветкой клавиатуры
Lenovo Legion K500 напрямую, без Lenovo Legion Accessory Central. Здесь собрано всё,
что подтверждено. Всё, чего здесь нет, считай неизвестным.

---

## 0. Главные правила (соблюдай всегда)

1. **Не придумывай байты.** Используй только формат из раздела 3. Если нужна функция,
   которой здесь нет (например, свой цвет для каждой клавиши), честно скажи, что протокол
   её не поддерживает или что она не подтверждена.
2. **Каждая команда = две передачи**: сначала feature report, потом output report
   (раздел 3). Без feature report клавиатура пакет игнорирует.
3. **Один пакет — один цвет.** В режиме customize все выбранные клавиши горят ОДНИМ
   цветом, невыбранные выключены. Отдельного цвета для каждой клавиши нет (раздел 5).
4. **Береги клавиатуру**: не шли пакеты чаще ~10 раз в секунду, по умолчанию 3–5
   (раздел 7, возможный износ flash-памяти).
5. **Перед работой скрипта** пользователь должен закрыть Lenovo Legion Accessory
   Central, иначе она может перезаписывать подсветку.
6. Код пиши для **Windows, Python 3.11 (32-bit), библиотека `hidapi`**
   (`pip install hidapi`, импортируется как `import hid`).

## 3. Формат команды

### 3.1. Последовательность

Каждая смена подсветки — ровно две передачи на интерфейс 3:

1. **Feature report** (USB `SET_REPORT`, `wValue=0x0300` = Feature, report ID 0), 8 байт данных:
   ```
   14 00 5A 00 00 00 00 00
   ```
   В hidapi: `dev.send_feature_report(b"\x00" + bytes([0x14,0x00,0x5A,0,0,0,0,0]))`
   (первый байт `0x00` = номер отчёта 0, всего 9 байт).

2. **Output report**: 64 байта данных без report ID, уходят в endpoint 0x04.
   В hidapi: `dev.write(b"\x00" + payload64)` (65 байт, первый `0x00` = «без report ID»).

Ответа от клавиатуры ждать не нужно. Контрольной суммы нет.

### 3.2. Раскладка 64-байтного пакета (`payload64`)

| Смещение | Длина | Значение |
|---|---|---|
| `0x00` | 1 | всегда `0x01` |
| `0x01` | 1 | режим (таблица 3.4) |
| `0x02` | 1 | яркость: `0`, `1`, `2` (2 = максимум) |
| `0x03` | 1 | скорость эффекта: `0`..`3` (3 = быстрее всего) |
| `0x04`–`0x0F` | 12 | нули |
| `0x10`–`0x2F` | 32 | палитра: 8 слотов по 4 байта `R, G, B, 0x00` |
| `0x30`–`0x3F` | 16 | маска клавиш (только режим customize), 128 бит |

Слоты палитры:
- слот 0 (`0x10`–`0x12`) — **основной цвет** (static, breathing, starlight, fading trace, customize);
- слот 1 (`0x14`–`0x16`) — **второй цвет** (starlight dual);
- слот 2 (`0x18`–`0x1A`) — третий цвет (используется редко).

Цвет — любые значения 0–255 на канал. В захвате встречаются `FF D4 00`, `CC FF F9`, `FF E6 E6`.
Плавное затухание делай умножением RGB на коэффициент 0..1.

### 3.3. Палитра по умолчанию (байты 0x10–0x2F)

Приложение Lenovo всегда заполняет все 8 слотов так, а потом подставляет свои цвета в нужные слоты:
```
слот0: RR GG BB 00   (основной цвет)
слот1: FF FF FF 00
слот2: 00 FF 00 00
слот3: 00 00 FF 00
слот4: FF 00 FF 00
слот5: FF FF 00 00
слот6: 00 FF FF 00
слот7: 00 00 00 00
```

### 3.4. Режимы (байт 0x01)

| Код | Режим | Цвета |
|---|---|---|
| `0x01` | Static — вся клавиатура одним цветом | слот 0 |
| `0x02` | Spiral | встроенные |
| `0x03` | Laser | слот 0 |
| `0x04` | Drifting | встроенные |
| `0x05` | Fading trace (подсветка нажатых клавиш) | слот 0 |
| `0x06` | **Customize** — горят клавиши из маски | слот 0 + маска |
| `0x07` | Breathing | слот 0 |
| `0x08` | Breathing rainbow | встроенные |
| `0x09` | Starlight (мерцающие звёзды) | слот 0 |
| `0x0A` | Starlight dual | слоты 0 и 1 |
| `0x0B` | Surfing | встроенные |

Static с цветом `00 00 00` = подсветка выключена.

### 3.5. Маска клавиш (байты 0x30–0x3F)

Клавиша включена, если в байте `0x30 + byte` установлен бит `1 << bit`
(byte и bit — из таблицы раздела 4). Пример: ESC = byte 0, bit 0 → `payload[0x30] |= 0x01`;
T = byte 4, bit 5 → `payload[0x34] |= 0x20`.

Маска учитывается только в режиме `0x06`. В других режимах — нули.

### 3.6. Примеры реальных пакетов из захвата

Static, синий (`00 00 FF`), яркость 2, скорость 3:
```
01 01 02 03 00 00 00 00 00 00 00 00 00 00 00 00
00 00 FF 00 FF FF FF 00 00 FF 00 00 00 00 FF 00
FF 00 FF 00 FF FF 00 00 00 FF FF 00 00 00 00 00
00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
```
Customize, зелёный, клавиши ESC, F1–F4, A, S, D, F:
```
01 06 02 03 00 00 00 00 00 00 00 00 00 00 00 00
00 FF 00 00 FF FF FF 00 00 FF 00 00 00 00 FF 00
FF 00 FF 00 FF FF 00 00 00 FF FF 00 00 00 00 00
1F 00 00 00 00 00 1E 00 00 00 00 00 00 00 00 00
```
(`1F` в байте 0x30 = ESC+F1..F4; `1E` в байте 0x36 = A,S,D,F.)

Если твой код собирает другие байты для таких же входных данных — в нём ошибка.

## 5. Что протокол умеет и чего не умеет

**Умеет:**
- задать один цвет всей клавиатуре (static);
- зажечь любой набор клавиш одним цветом, остальные выключить (customize);
- запустить встроенные эффекты с 1–2 цветами, яркостью и скоростью;
- быстро менять пакеты, получая программную анимацию: меняются маска и цвет.

**Не умеет (по всем имеющимся данным):**
- разные цвета на разных клавишах одновременно. В захвате видно: выбрав в приложении Lenovo
  сначала красный для ASDF, а потом жёлтый для других клавиш, приложение шлёт ОДИН пакет
  с жёлтым цветом и всеми клавишами в маске;
- «фон одного цвета + отдельные клавиши другим цветом» в одном кадре;
- плавную яркость отдельной клавиши. Плавность бывает только у всего кадра сразу.

Если пользователь просит такое, объясни ограничение и предложи замену из раздела 6.
Не изобретай «секретные» пакеты. В приложении Lenovo (legion_hid.exe, классы `K500Extra`,
`KeyMatrix`) могут найтись другие команды, но пока они не подтверждены — их нет.

## 6. Как проектировать эффекты при ограничении «один цвет на кадр»

Кадр = (режим 0x06, цвет, маска). Анимация = последовательность кадров.

Приёмы:
- **Появление и исчезновение клавиши** — добавлять и убирать её из маски.
- **Плавное затухание** — менять яркость цвета всего кадра (RGB × k). Действует сразу на все горящие клавиши.
- **Волна** — маска из клавиш, у которых `|колонка − x(t)| < ширина`; `x` растёт со временем.
  Для диагонали используй `колонка + ряд`.
- **Звёзды** — случайные клавиши живут в маске 2–5 секунд.
- **Пульс** — маска из всех клавиш, яркость цвета по синусоиде.
- **Смена «сцен»** — разные цвета в разные моменты времени, а не одновременно.
- **Встроенные эффекты** (starlight dual и др.) — одна команда, без потока пакетов.
  Это лучший вариант для фоновой работы.

Не делай быстрое чередование двух цветов, чтобы «смешать» фон и звёзды: будет мерцание,
а число записей удвоится.

Пример: эффект «Ranni» (Elden Ring) реализован в `ranni.py`. Там голубые звёзды
и лунная волна сменяются фиолетовым импульсом Dark Moon раз в 40–90 секунд.
Вариант `--hw` — встроенный starlight dual: тёмно-синий + циан.

## 7. Неизвестное и риски

- **Запись во flash.** Неизвестно, сохраняет ли клавиатура каждую команду в энергонезависимую
  память. OpenRGB помечает режимы как автосохраняемые. Проверка: задать цвет скриптом,
  переподключить USB. Если цвет сохранился — вероятно, пишет. Тогда длительная анимация
  может изнашивать память: держи частоту кадров низкой (≤5/с), а для фона используй
  встроенные эффекты.
- **Конфликт с приложением Lenovo** — закрывай Legion Accessory Central.
- **Несколько коллекций на интерфейсе 3 в Windows** — открывай ту, у которой
  `usage_page == 0xFF01` и `usage == 0x01`. Если таких нет, бери любую с `interface_number == 3`.

## 8. Эталонная реализация (проверена по захвату)

```python
import hid

VID, PID, INTERFACE = 0x17EF, 0x60D5, 3
FEATURE = bytes([0x14, 0x00, 0x5A, 0x00, 0x00, 0x00, 0x00, 0x00])
DEFAULT_PALETTE = bytes([
    0xff, 0x00, 0x00, 0x00,  0xff, 0xff, 0xff, 0x00,
    0x00, 0xff, 0x00, 0x00,  0x00, 0x00, 0xff, 0x00,
    0xff, 0x00, 0xff, 0x00,  0xff, 0xff, 0x00, 0x00,
    0x00, 0xff, 0xff, 0x00,  0x00, 0x00, 0x00, 0x00,
])
# KEYS: список (имя, байт, бит, ряд, колонка) из таблицы раздела 4, в том же порядке.

def find_path():
    devs = [d for d in hid.enumerate(VID, PID) if d["interface_number"] == INTERFACE]
    for d in devs:
        if d.get("usage_page") == 0xFF01 and d.get("usage") == 0x01:
            return d["path"]
    if not devs:
        raise RuntimeError("K500 не найдена")
    return devs[0]["path"]

def build(mode, color1=(0, 0, 0), color2=None, brightness=2, speed=3, mask_keys=()):
    buf = bytearray(64)
    buf[0x00] = 0x01
    buf[0x01] = mode
    buf[0x02] = max(0, min(2, brightness))
    buf[0x03] = max(0, min(3, speed))
    buf[0x10:0x30] = DEFAULT_PALETTE
    buf[0x10:0x13] = bytes(color1)
    if color2 is not None:
        buf[0x14:0x17] = bytes(color2)
    for byte, bit in mask_keys:          # пары (байт, бит) из таблицы
        buf[0x30 + byte] |= 1 << bit
    return bytes(buf)

def send(dev, payload64):
    dev.send_feature_report(b"\x00" + FEATURE)
    dev.write(b"\x00" + payload64)

dev = hid.device()
dev.open_path(find_path())
send(dev, build(0x01, (0x10, 0x10, 0x60)))                 # static, тусклый синий
send(dev, build(0x06, (0x00, 0xC0, 0xFF), mask_keys=[(0, 0)]))  # только ESC, циан
dev.close()
```

Полные файлы: `k500.py` (библиотека), `k500_test.py` (пошаговый тест), `ranni.py` (эффект).

## 9. Как работать с пользователем

1. Новую идею сначала проверяй коротким тестом (одна команда, потом вторая) — так пользователь видит, что работает.
2. В анимациях всегда делай выход по Ctrl+C, после которого остаётся спокойный статичный цвет.
3. Частота кадров — параметр командной строки, по умолчанию 3–5.
4. Если пользователь пишет «не работает», попроси: вывод `hid.enumerate(0x17EF, 0x60D5)`,
   текст ошибки и закрыто ли приложение Lenovo.
5. Говори прямо, что подтверждено (разделы 3–4), а что — нет (раздел 7).
