# Lenovo Legion K500 — RGB-протокол

Подтверждено:
- **Драйвер OpenRGB**: `Controllers/LenovoControllers/LenovoLegionK500Controller/LenovoK500Controller.cpp`,
  функция `LenovoK500Controller::SetMode` (MR !3472, коммит `799113942c`, 26.08.2026).
- **Захват 2026** (приложен к MR !3472, `k500-wireshark.zip`): `k500.pcapng`, `k500-customize.pcapng`, `k500-all.pcapng`.
- **Захват 2021** (issue #1553, `Wireshark.7z`): по файлу на каждый режим.

Оба захвата сняты с официального Lenovo Legion Accessory Central и совпадают по формату.
`k500.py` собирает пакеты, совпадающие с захватом байт в байт.

## Транзакция (интерфейс 3, VID 17EF, PID 60D5)

Каждая смена подсветки = две передачи:

1. **Feature report** — `SET_REPORT`, `wValue=0x0300` (Feature, report ID 0), `wIndex=3`, 8 байт:
   `14 00 5A 00 00 00 00 00`.
   В hidapi: `send_feature_report(b"\x00" + те_8_байт)`.
2. **Output report** — interrupt OUT, endpoint `0x04`, **64 байта, без report ID**.
   В hidapi: `write(b"\x00" + 64_байта)` (65 байт, первый `0x00` = «нет report ID»).

Контрольной суммы нет: в захвате между соседними пакетами меняются только поля цвета и маски.

## Формат 64-байтного пакета

| Смещение | Значение |
|---|---|
| `0x00` | `0x01` (константа) |
| `0x01` | режим: `01` static, `02` spiral, `03` laser, `04` drifting, `05` fading trace, `06` customize, `07` breathing, `08` breathing rainbow, `09` starlight, `0A` starlight dual, `0B` surfing |
| `0x02` | яркость `0..2` |
| `0x03` | скорость `0..3` |
| `0x04..0x0F` | `00` |
| `0x10..0x2F` | палитра: 8 слотов по 4 байта `R G B 00`. Слот 0 = цвет 1, слот 1 = цвет 2 (starlight dual), слот 2 = цвет 3 |
| `0x30..0x3F` | маска клавиш (customize): 128 бит, клавиша = `байт*8 + бит` |

Палитра по умолчанию из захвата: `RR GG BB 00 | ff ff ff 00 | 00 ff 00 00 | 00 00 ff 00 | ff 00 ff 00 | ff ff 00 00 | 00 ff ff 00 | 00 00 00 00`.
В OpenRGB `default_palette` отличается в слотах 5–6 — это ошибка OpenRGB, в `k500.py` взята палитра из захвата.

Порядок клавиш (байт/бит маски) — таблица `k500_matrix` OpenRGB. Проверено по `k500-all.pcapng`, где по очереди выбраны все клавиши:
104 из 104 совпали (`tools/verify_all.py`).

## Поклавишный цвет

**Индивидуального RGB для каждой клавиши в этом протоколе нет.** В режиме customize пакет несёт один цвет (слот 0) и маску:
отмеченные клавиши горят этим цветом, остальные выключены. Это видно в захвате `k500-customize`:
после выбора жёлтого и добавления Num7 приложение шлёт один пакет — жёлтый цвет и все ранее выбранные клавиши
(ASDF, ESC, F1–F4, Num7). Отдельного цвета у ASDF в пакете нет.
OpenRGB тоже помечает устройство `@direct :x:` (нет покадрового режима).

Если в `legion_hid.exe` (`K500Extra`, `KeyMatrix`) есть другая команда, это пока не подтверждено ни одним захватом.

## Неизвестно

- Пишет ли клавиатура каждую команду во flash. OpenRGB ставит всем режимам `MODE_FLAG_AUTOMATIC_SAVE`.
  Проверка: задать цвет скриптом, переподключить USB. Если цвет сохранился — частая анимация может изнашивать память.
